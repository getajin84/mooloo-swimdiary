# 주간 제작 에이전트 지시서 (Claude 예약 작업이 매주 읽고 실행)

너는 '물루의 수영일기' 인스타 4컷 연재의 제작 담당이다. 이 저장소의 코드와 기존 에피소드를 기준으로 다음 주 분량을 만든다.

## 1. 현황 파악
- `content/state.json`의 posted, `content/queue/`의 EP 폴더, `render/episodes*.js`를 읽어 마지막 에피소드 번호 N을 확인한다.
- 새로 만들 범위: EP.(N+1) ~ EP.(N+21). 21편 = 7일치. 반드시 3의 배수 단위로 만든다(그리드 보호).
- `agent/ideas.md`에 사용자가 적어 둔 원고·아이디어가 있으면 그것부터 우선 사용하고, 쓴 항목은 체크 표시한다.
- 지난 에피소드 제목·팁과 겹치지 않게 주제를 정한다.

## 2. 캐릭터·연출 규칙 (설정북 그대로)
- 김물루(27, 무난한 패션, 수영에 진심, 덜렁이, 물방울 삐침머리) / 이윤슬(수영 패셔니스타·인플루언서) / 엄마(응원+걱정, 무리하면 큰소리) / 아빠 김태랑(전 국가대표, 부상 은퇴, 태랑모터스 운영, 무심한 한마디) / 캐치(천재견 웰시코기, 대사는 '멍!').
- 그림체: `render/chars.js`의 파스텔 색연필 스타일만 사용. 새 소품은 에피소드 파일 안에 로컬 함수로.
- 구성: 표지(물 위 탑뷰) + 제목 + 컷 4장. 마지막 컷은 '물루 TIP' 박스. 업로드 시간 표기 금지.
- 팁은 사실에 맞고 안전하게. 건강 관련은 "계속되면 진료" 수준으로만.

## 3. 제작
- 새 파일 `render/episodes_wNN.js`(module.exports = 배열)를 만들고 `render/all.js`의 파일 목록에 추가.
- 표지 수면 띠가 부족하면 `render/assets/water.py`의 offset 목록을 늘려 dayK.png를 생성.
- `cd render && npm i && node build.js <번호들>` → `python3 sheet.py`로 미리보기를 만들어 **직접 보고** 겹침·잘림을 고친다(최소 1회).
- `python tools/export_queue.py <시작> <끝>`으로 대기열(JPEG+캡션) 생성.

## 4. 승인 요청
- 새 브랜치 `draft/ep<시작>-<끝>`에 커밋하고 main으로 PR을 연다. **절대 main에 직접 푸시하지 않는다.**
- PR 본문: 7일치 표(일차·에피소드 제목·팁 한 줄), 피드 미리보기 이미지와 에피소드별 6장 시트 이미지를 포함.
- PR을 사용자가 병합하는 순간이 승인이다. 병합 후 매일 GitHub Actions가 3편씩 자동 게시한다.
- 마지막으로 PR 링크를 한 줄로 보고하고 끝낸다.
